# EFA Spor Aletleri — Web Sitesi

Profesyonel spor salonları, fitness merkezleri ve antrenman alanları için yerli, sağlam ve performans odaklı spor ekipmanları üreticisi **EFA Spor Aletleri**'nin modern ve bağımsız web sitesi.

![EFA Spor Aletleri](images/cok-fonksiyonlu-sistem.jpeg)

---

## 🚀 Özellikler

* **Saf ve Hızlı Altyapı:** Herhangi bir derleme (build) veya sunucu ihtiyacı olmaksızın doğrudan **HTML5, CSS3 ve Vanilla JavaScript** ile çalışır.
* **Modern & Agresif Tasarım:** Siyah ve kırmızı tonlarında endüstriyel spor ekipmanı kimliği, şık tipografi ve duyarlı (responsive) tasarım.
* **Ürün Grupları & Teknik Detay Modalı:** Çok fonksiyonlu istasyonlar, rack & bench sistemleri ve depolama ünitelerinin teknik profil, taşıma kapasitesi ve garanti detayları.
* **Bakım & Onarım Hizmetleri:** Çelik halat/makara değişimi, sünger ve antibakteriyel deri döşeme revizyonu, gazaltı şasi kaynağı, elektrostatik fırın boya, CNC yedek parça üretimi ve periyodik salon bakım anlaşmaları.
* **Hızlı Teklif & WhatsApp Entegrasyonu:** Teklif isteme modalı, interaktif iletişim formu ve doğrudan WhatsApp üzerinden teknik resim/mesaj gönderme imkânı.

---

## 📁 Dosya Yapısı

```
├── index.html          # Ana sayfa, bölümler ve modallar
├── style.css           # Tasarım, responsive gridler, animasyonlar ve temalar
├── script.js           # Mobil menü, modal mantığı, teklif formları ve WhatsApp yapılandırması
├── images/             # Gerçek ürün ve atölye fotoğrafları
└── README.md           # Proje dokümantasyonu
```

## 🛠️ Nasıl Çalıştırılır?

1. Projeyi bilgisayarınıza indirin veya klonlayın:
   ```bash
   git clone https://github.com/doodlesz/efa-spor-aletleri-web.git
   ```
2. Klasör içerisindeki `index.html` dosyasına çift tıklayın. Tarayıcınızda anında açılacaktır.

## ⚙️ İletişim & WhatsApp Ayarları

WhatsApp ve telefon bilgilerinizi güncellemek için `script.js` dosyasının ilk satırlarındaki `CONFIG` nesnesini düzenleyebilirsiniz:

```javascript
const CONFIG = {
  whatsappNumber: "905550000000", // WhatsApp numaranız
  phone: "+90 (555) 000 00 00",
  email: "info@efaspor.com",
  address: "Sanayi Bölgesi, Metal & İmalat Sanayi Sitesi, No: 42, Türkiye"
};
```
